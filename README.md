# spark-pool-selection-service
REST API for intelligent Spark instance pool selection, using availability data and business rules to identify the pool with the highest probability of successful job execution while supporting instance type constraints.

## Documentação

- [Requisitos](docs/requisitos.md): o que o serviço precisa fazer, separado entre pedido, derivado e premissa assumida, com rastreabilidade para a arquitetura.
- [Arquitetura](docs/arquitetura.md): o desenho do sistema, cada escolha de ferramenta com as alternativas descartadas, o algoritmo de seleção e o plano de implementação.
